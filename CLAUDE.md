## The repo
- Vite multi-page site; root is `site/`.
- Game data: `site/src/data/games.json`. Game pages are generated by `scripts/gen-pages.mjs`.
- Run: `npm run dev` → http://localhost:5173. Phone on the same Wi-Fi: `npm run dev -- --host`.
- Branch `lively` holds the runaway-idea work. `main` deploys through GitHub Actions.
- Dev-only test pages (`*-test.html`) are not build inputs and never deploy.

## How we work
- One step at a time: say what it creates, wait for Ahmed's "go", build, test, report, update the checklist.
- Visual work: describe the picture back, or ask for a sketch or reference, before building.
- A question is not a request: answer with pros, cons and one plain recommendation. Build only on "go".
- Test with real input in headless Chrome (puppeteer-core in the session scratchpad): 1440 and 390 px, light and dark, 0 console errors, weight measured.
- Ahmed judges feel. A step is `✅ DONE` only after his approval.
- Ask before every commit. Never push to `main` without his OK. Push details are in Claude's memory.

## Copy rules (all site text)
- Capitals only for names (games, achievements, job titles, products); sentence case elsewhere.
- UK spelling. No shorthand ("dev", "+", "&"). No em dashes.
- Describe Ahmed's work in his words. Never copy tools or skills from his CV profile without asking.
